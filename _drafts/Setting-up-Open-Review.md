My colleagues and I have been using OpenReview.net for the Workshop on Computational Fair Division at IJCAI for a few years now. The UI could use some improvements. Here are some tips and tricks we've needed for setting up the platform. 

<!--more-->

## Settings

The main setup page is `https://openreview.net/forum?id=XYZ`. You should see several tabs on top:
* Revision
* Bid Stage
* Review Stage
* Decision Stage
* Comment Stage
* Submission Review Stage
* Post Submission
* Review Registration
And several tabs on the bottom:
* Comment
* Recruitment
* Remind Recruitment
* Paper Matching setup
